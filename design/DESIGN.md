# Nexys VIEW — 디자인 브리프 (Claude Code 필독)

임시 표시명: **Nexys VIEW** (설정 파일 `branding.json`의 `displayName` 한 줄로 변경 가능하게 구현).
이 문서는 **스타일링 지침**이다. 화면 구성과 기능 설계는 프로그램 설계(NAVIGATOR / VIEW / ANALYSIS / REPORT)를 우선하고,
레퍼런스는 그 위에 입히는 옷이다. 레퍼런스를 그대로 베끼지 말고 **원칙을 적용**한다.

## 0. 최우선 원칙 (이 순서대로)
1. **속도.** 어떤 조작도 100ms 안에 반응하고, 그래프 팬·줌은 60fps. 버벅임은 기능 미완성보다 나쁜 결함으로 취급한다. (§5)
2. **색은 데이터만 쓴다.** 프로그램 틀(배경·패널·경계·텍스트·아이콘)은 무채색. 유채색은 그래프 곡선, 상태 표시, 포인트 색 1개뿐.
3. **AI 슬롭 금지.** §6 금지 목록을 어기면 다시 만든다.
4. **드래그 앤 드롭이 기본 조작.** 메뉴를 열지 않아도 채널을 끌어 놓는 것만으로 분석이 시작된다. (§4)

## 2. 브랜드 (design/brand/)
- `Logo.png` (또는 `Logo.jpg`): 좌측 상단 내비게이션 헤더에 표시. 높이 20px 기준, 좌측 여백 16px. 옆에 표시명(§3 폰트, 13px, 600).
- `AppIcon.png`: 원형 아이콘. 창 제목 표시줄·작업 표시줄·exe 아이콘(.ico 변환, 16/32/48/256px)에 사용.
- DXD, the vendor, 기준 도구 등 타사 이름·로고·아이콘은 어디에도 넣지 않는다.

### 타이포
- UI: **Pretendard** (한/영, 번들 포함). 13px 기본, 12px 보조, 11px 대문자 라벨(자간 +0.04em).
- 숫자·값: **JetBrains Mono** 또는 Pretendard의 tabular-nums. 측정값은 큰 숫자(20~28px, 500) + 작은 단위(12px, muted).
- 제목은 16px 600까지. 그 이상 크기는 쓰지 않는다.

### 간격·형태
- 8px 그리드. 패널 내부 패딩 12~16px. 모서리 반경 4px (카드), 2px (버튼·입력). 그림자 없음(경계선으로 구분).
- 아이콘: **Lucide** 라인 아이콘 16px, stroke 1.5. 이모지·채움형 컬러 아이콘 금지.

## 4. 조작 (기준 도구 수준 UX)
### 드래그 앤 드롭
| 끄는 것 → 놓는 곳 | 결과 |
|---|---|
| 채널 → 빈 VIEW 영역 | 시간축 그래프 1개 생성, 곡선 추가 |
| 채널 → 기존 그래프 | 그 그래프에 곡선 추가 (같은 단위는 축 공유, 다른 단위는 보조 축) |
| 채널 → 그래프의 Y축 | 그 축에 추가 |
| 채널 2개(Ctrl 선택) → 빈 영역 | XY 그래프 (첫 선택 X, 둘째 Y) |
| 채널 → 테이블 영역 | 값 테이블 열 추가 |
| 그래프 → 다른 그래프 위 | 위치 교환 / 분할 안내선 표시 |
| 파일(.tdms/.tdm/.dxd/.csv) → 창 아무 곳 | NAVIGATOR에 로드 |
- 드래그 중 **놓일 자리 미리보기**(점선 테두리)를 60fps로 표시. 놓으면 즉시 그려짐.

### 그래프 조작
- 휠: 줌(커서 기준). 드래그: 팬. 더블클릭: 전체 보기. Shift+드래그: 영역 줌. 
- 클릭: 커서 A, Shift+클릭: 커서 B. Δ값·구간 통계는 그래프 상단 얇은 띠에 표시.
- 범례 클릭: 곡선 숨김/표시. 범례 드래그: 다른 그래프로 이동.
- 모든 조작은 Undo/Redo (Ctrl+Z/Y).

### 레이아웃
- 좌측: NAVIGATOR(파일·채널 트리, 검색). 가운데: VIEW 캔버스(분할 가능). 우측: 속성 패널(선택 객체).
- 상단: 모드 탭 NAVIGATOR / VIEW / ANALYSIS / REPORT. 모드 전환 즉시(지연 0).
- 패널 폭은 드래그로 조절, 더블클릭으로 접기. 레이아웃은 자동 저장.

## 5. 성능 요구 (측정해서 보고)
| 항목 | 목표 | 방법 |
|---|---|---|
| 팬·줌 | 60fps (프레임 ≤16ms) | 픽셀 열당 min/max 축약, 화면 폭만큼만 그림 |
| 대용량 채널 | 10M 샘플 채널을 끌어 놓으면 100ms 내 표시 | 로드 시 LOD 피라미드(2^k 축약) 백그라운드 생성, 줌 레벨별 선택 |
| 파일 열기 | 1GB TDMS 첫 화면 1초 내 | 메모리 맵 + 지연 로드(채널 메타 먼저, 값은 요청 시) |
| UI 스레드 | 16ms 이상 점유 금지 | 파싱·축약·통계는 전부 백그라운드, 결과만 디스패치 |
| 목록 | 채널 10,000개 트리 스크롤 매끄럽게 | 가상화(virtualizing) 컨트롤 |
| 렌더러 | SkiaSharp 기반 자체 또는 ScottPlot 5 — 60fps 목표 미달이면 교체 | 프레임 시간 로그를 상태줄에서 볼 수 있게 (개발자 모드) |
| 피드백 | 스피너 대신 즉시 부분 표시 | 로딩 중에도 이미 읽은 채널은 바로 보임 |
- 셀프 테스트에 **프레임 시간·응답 시간 측정**을 포함하고 목표 미달 항목을 보고서에 적는다.

## 6. AI 슬롭 금지 목록
- 보라·파랑 그라데이션, 글래스모피즘(블러 카드), 네온 글로우, 그림자 중첩
- 이모지, 컬러 채움 아이콘, 장식용 일러스트
- 카드 안의 카드 안의 카드, 과도한 둥근 모서리(8px 초과), 과한 여백
- 한 화면에 포인트 색 2개 이상, 유채색 버튼 남발
- 무의미한 KPI 카드, 가짜 통계, 장식용 스파크라인
- 제목 크기 20px 초과, 폰트 3종 초과, 자간 과다
- 설명 없는 아이콘 버튼(툴팁 필수), 중앙 정렬 본문

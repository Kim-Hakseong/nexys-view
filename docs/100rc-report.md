# 1.0.0-rc 보고 — BUS 모드(MIL-STD-1553 / ARINC 429) · ICD 모듈 · DXD 리더 이전 — 2026-10-29

측정은 전부 셀프테스트(`--v100rc`, `--v0100`, `--v094`, `--stress --iter 50`, `--selftest`)가 1440×900 페이지에서 실제 DOM 이벤트로 돌린 것. 데이터는 가상 생성(내장 샘플·120 MB 100만 레코드 캡처·더미 ICD 10메시지/40워드). 실물 캡처 검증은 아직 하지 않았다.

## 바뀐 것
- **BUS 모드**(툴바 BUS, Ctrl+3): 빈 화면(OPEN / 1553 SAMPLE / 429 SAMPLE), 정렬·열 선택·시간 단위(상대 s / 절대 µs / Δ ms)·키보드 이동·오류 행 톤, 필터(RT·SA·T/R·버스·오류·텍스트) + 프리셋, 디코드(원시 hex·비트·10진 + ICD 이름·EU, ICD 적용/해제), 워드 추이 차트, 세션 통계, CSV / CSV·EU.
- **ARINC 429**: 30 B 레코드 리더·가상 샘플 라이터, 레이블(옥탈)·SDI·데이터·SSM·패리티 열, 레이블/SDI/SSM/패리티 필터, 디코드, 레이블별 통계.
- **ICD 모듈**(설정 → ICD export module): IMPORT(CSV·XLSX 열 매핑 자동 인식 + 수동, 허브 JSON·메시지 XML) · EDIT(메시지·워드 표, error/warning 검증) · EXPORT(시뮬레이터 프로젝트 복합문서 · 메시지 XML · 커스텀 디바이스 XML · 자동화 스크립트, 미리보기, XSD 검사 + 재판독 비교). 허브 JSON 스키마 1.0.
- **DXD 리더**를 Core로 이전(외부 프로젝트 참조 제거), 정답지 JSON과 비트 일치 xUnit 4/4.
- 설정 화면 정리(테마·BUS 시간 표시·드롭 규칙·모듈·템플릿 폴더·프로필 폴더), 도움말에 BUS·ICD 절, 정보 창은 버전·피드백만.
- 0.9.4 대비 메모리 기준선: `--selftest` memory_ws_mb 0.9.4 524.7 MB(3회 중앙값) vs 0.10.0 523.0 MB → 차이 −1.7 MB. 관문은 500 → 600 MB로 상향(0.9.4 자체가 이미 525 MB였고 1553 기능과 무관).

## 아직 확인하지 않은 것 (실물 필요)
- 1553 타임태그 단위·오류 비트 이름·버스 로드 계산식은 가상 데이터와 공개 소스 기준이다.
- 시뮬레이터 프로젝트 파일이 시뮬레이터에서 열리는지, 메시지 XML을 DB 유틸리티가 가져오는지, 커스텀 디바이스 XML이 실시간 테스트 시스템에 로드되는지.
- 자동화 스크립트는 시뮬레이터 COM이 감지될 때만 켜지며(환경변수 `BUS_SIM_PROGID`), 실행은 하지 않았다.
